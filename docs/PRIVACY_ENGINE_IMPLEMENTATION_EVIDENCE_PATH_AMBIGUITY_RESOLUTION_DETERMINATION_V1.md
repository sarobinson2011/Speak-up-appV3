## 6. Evidence Semantics

> evidence availability != evidence sufficiency != requirement result

A bounded path means only that an exact later evidence and evaluation route is identifiable.

A still-ambiguous path means candidate evidence exists, but an exact formal-to-implementation relationship, choice position, or provenance relationship cannot be established from the fixed baseline without inference.

A missing-evidence-path classification would mean that no bounded candidate route can be identified. No Engineering[167] row receives that classification.

Code, tests, documentation, generated artifacts, deployment records, and runtime observations do not prove requirement satisfaction merely by existing.
