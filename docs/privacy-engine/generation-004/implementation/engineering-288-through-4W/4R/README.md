## Byte law and completion

The stream is the 34-byte `PE-G4-POTENTIAL-EQUALITY-PAIRS-V1\n` header followed by U32BE(left index) || U32BE(right index), for accepted numeric lexicographic i<j pairs. There are 91,157,454,636 candidate ranks; 1,169 fixed/fixed unequal-digest exclusions leave **91,157,453,467 required rows** and **729,259,627,770 exact bytes**. The descriptor has 426,984 tokens and 50 fixed entries in 18 digest groups, and is an exact retained input, not a stream hash.

Generation uses complement exclusion lookup. Replay uses `fixed[i]<0 || fixed[j]<0 || fixed[i]==fixed[j]`. These are independent predicate paths inside the same pinned native program; traversal, serializer and OpenSSL SHA implementation are shared. The retained small independent byte oracles and the new four-token Python oracle cover that boundary. No stronger claim of two independently authored complete implementations is made.

Each of 1,359 contiguous half-open segments covers at most 67,108,864 candidate ranks. SHA state is updated over actual serialized row bytes, starting with the header exactly once. Segment digests support checks; **their concatenation is never the whole-stream preimage**. `generated_whole_stream_sha256` is populated only at complete generation; `verified_whole_stream_sha256` requires complete matching predicate replay too. The final receipt states conditional mechanical identity only.
