# File-backed collector integration

`integrated_auth.collector.run(manifest, trusted_path, checkpoint, key_path, ...)` is the new entry point. The carrier is `CP4H-FILE-COLLECTOR-1`. `fixtures/integrated.py` exports the exact schema and examples. It contains the old request metadata with null byte fields and empty source maps, exact bounded record descriptors, lazy source/material maps, all three four-file bundles, canonical model file, selected evidence-contract file and canonical model digest. Every descriptor is `{path, bytes, sha256}`; paths are relative to and contained under the manifest directory. Metadata is a transport expectation, never a substitute for independent source-owned correspondence.

The existing ordered collector now accepts an internal adapter; the JSON carrier cannot inject Python callbacks. Legacy hex callers and the new file-backed path both use crypto_backend/bin/pe-rfc8032-stream, the unchanged CP4G pinned canonical RFC8032 adapter. The legacy carrier retains an allocation cap; the file-backed signed-message path does not have that cap. The CP4F historical integration module is retained unchanged as a historical negative fixture, not the new production entry point.

Acquisition verifies exact V2 length-prefixed object bytes and the final immutable outer profile. Crypto consumes exactly SIGN_DOMAIN || evidence.tsv || tokens.tsv || links.tsv. Tables bind the appointed issuer, scope/kind/identity constructors, exact table digests and final outer profile. The collector then binds profile/body/program/model/security/contracts, all source roles, source-owned seed closure, complete experiment/target/whole views and separate scope source assertions. Cross-bundle source correspondence binds every file length/hash, object, external record set and ledger source. Ledger prerequisites, exact/computational classifications, assessments, multiplicities, budgets, non-vacuity and signed-result consistency retain the accepted failure order.

Token validation compares a streaming expected row sequence generated from the source-bound scoped model against input bytes across arbitrary chunks. This establishes exact framing, every cell, order, uniqueness and full coverage without collecting supplied token rows or a supplied-ID set. The inherited model itself validates unique identities. Link validation reuses CP4B State/ModelIndex, which enforces legal membership, orientation, ordinals, strict lexical uniqueness and separate structural/potential cardinalities. Legal subset + uniqueness + equal cardinality establishes equality only because the exact complete required set/cardinality comes from the independently bound model. Structural and potential obligations are never collapsed into one total count.

New fixes demonstrated in tests: normalize a malformed source scope object's local grammar category to accepted INVALID-PROFILE-SCHEMA instead of allowing an unknown-category exception to abort the collector; map missing file reads to MISSING-EVIDENCE; suppress ledger/budget readiness when an adapter-level model/contract join fails. Interrupted stage writes cannot erase the prior valid collector commit.

Memory: source/material maps are lazy, with a 16 MiB per-object acquisition capability; external records have a 16 MiB cap, outer/model/contract/trusted contract 64 MiB, manifest 16 MiB, evidence row 1 MiB and signature 4096 bytes. These are disclosed implementation caps, not new wire limits. Token/link auxiliary state is O(complete finite model + chunk + longest legal row), not O(supplied rows). The retained finite assessor can still materialize a complete invocation dependency object, and the semantic outer/record adapters still parse bounded JSON blobs. No production-scale semantic-record ingestion claim is made. Exceeding a cap fails closed, never admits a smaller universe.

Authentication is implemented under an independently supplied key; competent appointment and semantic qualification remain independent authoritative inputs. ACTUAL mode always rejects. A successful conditional fixture neither appoints a real source authority nor admits a profile.
