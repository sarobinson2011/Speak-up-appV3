# 4J computation preflight

No full retained pair or link stream will be read, generated or hashed. Retained model and amendment bindings are inputs.

Implementation plan: privately spool consumed exact bytes; canonical JSON is indexed on disk, with 64 KiB read buffers, 64 KiB small-node materialization, 1 MiB ordinary string limit and depth 128. Large unescaped lowercase even hex strings are streamed. SQLite cache is capped at 8 MiB per active store. Model/token/ledger identity indexes remain proportional to their required universe; semantic payload size does not become a Python hex string. Disk holds exact copies, JSON indexes and exact invocation preimages. Unsupported inputs fail closed through capability failures.

Planned bounded larger conditional case: at most 512 finite outcomes per non-collision world, each a distinct 1024-byte observation, matched complete supports and exact independently calculated zero statistical distance. Expected profile 8–15 MiB; complete external directory 200–600 MiB and matching source traces of similar total size; no opaque padding. If too large for the 60-second bounded run, reduce observation width/count and state which legacy limit was actually exceeded. Fixture construction/signing estimated below 2 GiB RAM, validation target below 200 MiB plus model/index, scratch up to 5 GiB. Initial runtime uncertainty 10–60 seconds per bounded subprocess; hard timeout 60 seconds. At most three timed performance runs, at most 180 seconds total. Tests are correctness checks, not performance/conformance substitutes. Signing resource usage is measured separately.

Recovery plan: journal bound to carrier, trusted inputs and implementation; semantic acquisition resumes by rebuilding parser/index from exact verified prefix into a new private temporary store. Interrupted indexes are never authoritative and are discarded. Completed stages are re-acquired; hash/stat alone never substitutes for rereading exact bytes. Costs are full-prefix I/O, indexing and digest replay. No success after partial acquisition, processing interruption or incomplete semantic closure. Temporary stores are disposable; all authoritative files stay unchanged.

Implementation outcome: final JSON/assessor SQLite caches were tightened from the planned 8 MiB to 256 KiB per document/index. The bounded larger case uses 512 outcomes of 256 bytes each; actual measurements are in RESULTS-4J.md. No retained full stream ran.
