## Durable invocation example

```sh
mkdir -p work/4l-demo
python -m integrated_auth keygen --key work/4l-demo/key
python -m integrated_auth start --manifest fixtures/4L-E/manifest.json --trusted fixtures/4L-E/trusted.json --checkpoint work/4l-demo/journal --key work/4l-demo/key --new-bytes 53 --chunk-bytes 7 --seconds 50
python -m integrated_auth resume --manifest fixtures/4L-E/manifest.json --trusted fixtures/4L-E/trusted.json --checkpoint work/4l-demo/journal --key work/4l-demo/key --new-bytes 10000000 --auth-new-bytes 10000000 --quanta 3 --seconds 50
python -m integrated_auth resume --manifest fixtures/4L-E/manifest.json --trusted fixtures/4L-E/trusted.json --checkpoint work/4l-demo/journal --key work/4l-demo/key --seconds 50
```

Exit 3 means paused/interrupted; continue with resume. Exit 0 is conditional checks only, never actual admission; exit 2 means rejection. Progress is stderr; result is stdout. Preserve exact paths, source files, trusted contract, recovery key, main journal, `.stages` directory, scope byte/crypto journals and generated source job files. Changed paths/code/key require a new job. Corrupted or substituted receipts are not repaired by editing. No timestamp-based trust is used. Partial grouping restarts; complete indexes reuse only after exact source/artifact checks. See OCCURRENCE-ADAPTERS-4L.md and RECOVERY-4K.md for passes/replay.
