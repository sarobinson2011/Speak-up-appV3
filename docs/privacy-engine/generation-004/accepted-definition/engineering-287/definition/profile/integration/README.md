SOURCE-OWNED-BODY.txt and EXPRESSION-PROGRAM.json are exact constructed member bytes. They remain unadmitted. assemble_members.py regenerates them and implements the inherited three-member container framing. privacy_member.py implements S88's extended governing PRIVACY member, exact source/procedure binding and appointment shape/equality checks. It constructs no production outer profile without supplied appointment inputs.

evidence_auth.py preserves V2 payload/object preimages and authenticates exact externally regenerated evidence bytes across ROOT-ELIGIBLE, SCOPED-USED and NOT-APPLICABLE composition scopes. Its expected bytes and trusted appointment must come from independent source/model validation, never issuer assertions. The function cannot establish authority or admission by itself.

The two test modules distinguish in-memory synthetic transport/serialization fixtures from real source evidence. No test key, signed fixture or synthetic full-profile bytes/digest are saved.
