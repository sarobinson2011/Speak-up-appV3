# Proposed producer evidence carrier V2

Status: newly authored construction format, not an admitted protocol/source format. V1 retained evidence-contract.md remains immutable provenance. V2 explicitly replaces only the proposed producer's outer evidence framing; existing canonical TSE values, authorization/header/attempt/recovery/transcript/graph bytes remain exact opaque inner values. Appointing the interpretation and qualifying actual source evidence are separate admission obligations.

The exact magic is ASCII PE-G4-PRODUCER-EVIDENCE-V2 followed by NUL. It is followed by L64(ASCII phase), U64(record count), then every record in the retained 174-field directory's first-appearance order. Integers are unsigned 64-bit big-endian; L64 is U64(byte length) plus exact bytes. Each record is L64(ASCII name), one status octet, U64(instance count), then L64(instance) for each instance. Status 0 is INAPPLICABLE, 1 UNAVAILABLE, 2 PRESENT. Inapplicable and unavailable records have zero instances; present records have at least one. There is no omitted record, alternate ordering, extra field or trailing byte.

Each instance is U64(field count), then every field in the exact directory order: L64(ASCII field name), a tag byte, then L64(value) only when the tag is 1. Tag 0 is explicitly inapplicable; tag 1 preserves exact owning bytes. No other tag is legal. Inapplicability is permitted only where the exact phase schema declares it. A present empty byte value is distinct from absence and still requires validation under its owning semantic domain. The framing parser does not establish typed value validity, 16-slot cardinality, seven-call completion, authentication or authority.

The exact record-phase matrix is RECORD_PHASES in evidence_carrier.py and is exported in carrier-applicability.tsv. The phase-view record carries E/C in phase E; its authorization/D/Q0/mapping-profile/U/stage/attempt fields are inapplicable there. Gate phase-view carries the authorization-bound fields and does not duplicate E/C: the historical E/C remain bound by the immutable authorization coordinates and original E package. All other applicable fields remain present. AUTHORIZED component evidence is bound through the original authorization/component/carrier records; it is not a fresh current observation. Retrieval and recovery carry their exact retained packages in the existing owning evidence fields.

Unavailable records are explicit acquisition results, not completed negative facts. A diagnostic E package can contain unavailable evaluation-completion; it proves no D. Gate acquisition may lack unrelated predicate records without denying independently authenticated sufficient conflict. acquisition_status reports framing completeness only and never grants protocol permission. A present commit record is not evidence that commitment occurred. Source validators must independently prove all assertions, joins, phase applicability and semantic outcomes.

Decode consumes exactly the complete envelope, rejects unknown phases/statuses/tags, wrong field/record counts, impossible instance counts, omissions, duplicates, reordering, extra bytes and truncation. Encode/decode are lossless on accepted shape. Counts are bounded by available bytes before iteration. Source-specific witness formats are intentionally not guessed or executed.

Envelope phase, record statuses, field tags, instance counts/order and length metadata are included in the supplementary privacy inventory. They are potentially visible with the enclosing evidence; no new public disclosure or linkage permission is introduced. All actual observer/coalition visibility remains unestablished.
