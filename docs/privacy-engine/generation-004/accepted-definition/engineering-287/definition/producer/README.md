# Concrete producer dependency and custody construction

This implementation is a document-only dependency planner and graph constructor. It makes all nineteen retained prose conditions explicit. It is not a live producer, a source validator or a runtime authorized to produce E/D/U. Work-state inputs do not authenticate themselves.

The E and gate phase bases are separate. A pre-existing V is joined by exact inputs at consumption, not forced to execute after E fixation. Partial predicate acquisition does not block independently sufficient conflict; full E completion remains separately required. Reconciliation consumes the selected completed outcome. Final-gate acquisition requires fresh source evidence and the indivisible boundary. Static privacy assembly depends on declarations, avoiding a cycle through future runtime records.

The custody table enumerates potential access to individual evidence fields, including diagnostics, cache, public-chain observers and possible cross-context custody. Every row starts UNKNOWN; no private-access claim is invented. The augmented graph contains every inherited node and edge plus all potential control/custody edges. It does not filter actor edges or instantiate runtime equality, and role nodes do not appoint actors. The inherited model remains intact for exact provenance; its unresolved-condition labels are dispositioned here, not erased.

The proposed V2 carrier now explicitly defines phase applicability and inapplicable versus unavailable evidence. evidence_carrier.py implements lossless framing with strict malformed-input rejection; evidence-carrier-format.md defines its limits. It preserves owning canonical bytes and never substitutes an empty value for an absent fact. Exact source-owned witness formats/parsers and semantic validation remain outside this framing codec. required-realization-bindings.tsv identifies those inputs and the existing verifier correspondence and observer gaps precisely.

The next full canonical privacy/profile construction depends on those bindings. Repeating synthetic vectors cannot supply them. No new protocol policy approval is requested, and no implementation baseline is adopted.
