It maps the existing managed-local:live and managed-local:retired opaque-reference declarations to the exact retained manager source in both SYMBOLIC-U-ONE and SYMBOLIC-U-TWO. ## What changed

The producer derives ten direct assignments, thirteen related call sites, eleven reference reads and the source control of nine containing methods. It covers constructor initialization; quarantine's phase revocation, reference copy and subsequent live clear; disposal's no-retired early return, normal close continuation and retained-reference failure; recovery's old-handle disposition, allocation result, partial-object retention, initialization and validation, publication and exception cleanup. Each mapping carries exact source identity, expression, location, syntactic guards and ordered normal-continuation prefixes. Expected writes come from the defining AST independently of generated declarations and origin lists. The retained independent guard oracle remains the guard authority; coordinated omissions in the generator, cached inventory or catalogue cannot narrow the required source domain. The defining source and Authority.close source are separately pinned. The original opaque-reference declarations and prior presence, ordering, status, recovery embedding and SOC-closed completion checks are reused unchanged.

The constructed-path checker is a finite, pure source-structured model for this selected slice. It interprets no producer Python code and invokes no producer methods. It tracks reference variables and phase through conditional assignments and internal calls; opaque operations are explicit constructed normal/abrupt premises. Reference and phase predicates are computed; other predicate facts require explicit values and, where relevant, the exact constructed reference subject. Its source replay rejects removed/reordered effects, stale tokens, contradictory final slots, unsupported clears and invented closure claims.

Constructed stop points are partial model prefixes, not evidence of process death, durable state or actual bytecode interruption. Ordinary unspecified gates have a recorded normal-continuation premise in the constructed result. The helper does not prove that every premise/path is feasible; it does not model arbitrary callback behavior, context-manager suppression, hostile mutation or every intra-expression failure. Required source guards and complete selected source text remain available for inspection. A source-local result variable is invocation-qualified; distinct variables do not prove distinct underlying runtime objects, and the same constructed token is an explicit alias premise, never an inference from equal observed values.

## Reference, connection and representation boundaries

A no-db attribute predicate is a bounded source branch, not proof no external resources or obligations exist.

The new receipt retains the complete reviewed field correspondence and exact prior receipt identity. Sparse smoke evidence contains no _live/_retired snapshots or local a identities. The adapter leaves actual reference transfers and object/connection identities unavailable.
