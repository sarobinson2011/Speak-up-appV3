## 11. Authoritative Construction Framework

The complete current framework establishes:

1. A Protocol Generation is one uniquely identified, bounded and complete protocol semantic state.
2. A semantic change requires a distinct Protocol Generation.
3. Publication changes publication state and does not create or mutate protocol identity.
4. A successor must be complete and must not be a partial amendment, overlay, correction or mutation of its predecessor.
5. Succession is a directed relationship between two distinct published generations.
6. Succession preserves predecessor identity, published content, lifecycle record and historical truth.
7. A Protocol Specification derives from exactly one published Protocol Generation.
8. A specification derived from a different generation possesses a distinct specification identity.
9. Specification completeness requires complete normative representation of the governing generation.
10. A partial changed changed-text package cannot constitute a complete successor Protocol Specification.
11. Composition must preserve one authoritative normative home for each semantic requirement.
12. Every normative requirement requires stable identity and complete traceability.
13. Creation, review, protocol publication and specification publication remain distinct acts.
14. Protocol authority remains with each published generation for its own identified semantics.
15. No implementation, application, model, engineering determination, review or publication record acquires protocol authority.

The governing preservation rule is:

> predecessor G1 -> unchanged(G1)  
> accepted engineering clarification -> non-authoritative input  
> complete successor candidate G2c -> independent review  
> accepted G2c -> separate Protocol Publication  
> published G2 -> authority for G2 semantics

Forbidden paths include:

> G1 -> edited G1

> engineering determination -> protocol authority

> review -> publication

> partial changed text -> complete G2

> successor semantics -> retroactive predecessor meaning
