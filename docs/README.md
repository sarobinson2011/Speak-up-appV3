# Documentation Overview

This folder contains essential documentation for Speak-Up V3.

## Quick Reference

| File | Purpose | When to Use |
|------|---------|-------------|
| **WORKING_COMMANDS.md** | All tested commands (deploy, verify, interact) | Setting up, deploying, or debugging |
| **CONTRACT_ADDRESSES.md** | Current deployed contract addresses | Quick address lookup |
| **ARCHITECTURE.md** | Design decisions and rationale | Understanding why things work this way |
| **INTEGRATION.md** | Backend/frontend integration patterns | Building integrations |
| **UPGRADES_GUIDE.md** | UUPS upgradeable pattern reference | Upgrading contracts |

## For New Developers

Start here:
1. Read **WORKING_COMMANDS.md** - Get everything running
2. Read **CONTRACT_ADDRESSES.md** - Know what's deployed where
3. Read **ARCHITECTURE.md** - Understand the design

## For Integrators

Focus on:
1. **INTEGRATION.md** - Backend/frontend patterns
2. **CONTRACT_ADDRESSES.md** - Contract addresses to interact with

## For Contract Maintainers

Reference:
1. **UPGRADES_GUIDE.md** - How to safely upgrade
2. **ARCHITECTURE.md** - Design constraints to maintain
