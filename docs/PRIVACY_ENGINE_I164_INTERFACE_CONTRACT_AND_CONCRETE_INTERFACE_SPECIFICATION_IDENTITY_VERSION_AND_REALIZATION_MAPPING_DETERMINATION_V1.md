## 6. Construction Rule

The analysis applies:

candidate component
!= formal mapping

formal mapping
!= accepted mapping evidence

accepted mapping evidence
!= evidence-path boundedness

evidence-path boundedness
!= evidence availability

evidence availability
!= evidence sufficiency

evidence sufficiency
!= requirement assessment

requirement assessment
!= requirement result

The following inferences are prohibited:

- ABI -> Interface Contract identity;
- route -> Interface Contract identity;
- payload -> Concrete Interface Specification identity;
- function signature -> stable formal identity;
- file path -> formal identity;
- deployment address -> interface identity or version;
- runtime occurrence -> interface specification;
- test fixture -> published interface specification;
- database schema -> public Interface Contract;
- application response -> Published Result;
- unchanged syntax -> unchanged semantics;
- changed syntax -> changed semantics;
- version-like label -> authoritative interface version.

## 8. Candidate-Record Semantics

Candidate identifiers `C-I164-IFACE-001` through `C-I164-IFACE-053` are analysis-local coordinates only.

They are not:

- Interface Contract identities;
- Concrete Interface Specification identities;
- Protocol Surface identities;
- Protocol Operation identities;
- protocol subjects;
- interface versions;
- protocol authority;
- participant identities;
- or evidence-path states.

Version evidence classifications:

- `none`: no version-like evidence;
- `label-only`: a filename, title, comment, mode string or local constant resembles a version but has no established interface-version authority;
- `internal-schema`: an internal representation contains a local version field;
- `artifact-only`: a cryptographic or generated artifact identity exists but is not interface identity.

Binding classifications:

- `none`: no deployment or runtime binding;
- `configuration`: address, chain or environment configuration only;
- `deployment-candidate`: bounded deployment evidence exists without interface-identity assignment;
- `runtime-candidate`: bounded observation exists without interface-identity assignment;
- `test-only`: reproducible or fixture evidence only.
