## Source-supported distinctions

* The journal's 384,000-row atomic fail-closed ceiling is per journal, after authentication and before method processing. Accepted stale/error/unanswered and interrupted requests remain entries. It is not a global recovery or lifetime-retention bound.
* Event history has a 12,000-event implementation ceiling per session namespace. * Ownership has a 4,096-coordinate local ledger ceiling, with permanent chain/executor/nonce ownership and same-owner reuse. Shared historical signed-carrier writers remain in scope; all-ledger/all-writer lifetime multiplicity is not established.
* The 102-attempt and shared 16-slot/hold limits remain unchanged. Recovery of existing signing bytes is not a new charged attempt; a new authenticated request can nevertheless consume another journal entry. First-failure/retry once-only accounting and no-refund behavior are not modified. 101 ordinary / 61 ZK remain reviewed structural upper bounds only.
* Backup IDs consume the existing shared snapshot/partition resources (130/85) and retain RETAINED-UNCERTAIN bookkeeping. This is not a bound on external backup files, restoration copies or their sizes, and not evidence of backup completion. Backup remains kernel-only.
* status has no allowance-consuming or limiting state update. Successful state reads and sequential close/recover cycles are not bounded by action-attempt counters. This is a static admitted-repeatability conclusion under the source's successful guards, not an endurance/durability experiment. It does not assert that every transient read is persisted or required to be retained.
* Managed recovery builds an export for validation. The source does not automatically persist every such transient object. Independently retained exports, traces, instances and restoration copies need their own inventories and source-owned retention obligations. Epoch is local to an instance and resets at construction; it is not a global instance identity.

The physical-storage expression sums exact bytes of distinct retained containers, including copies, SQLite indexes/journals and temporary/staging evidence where applicable. It does not multiply physical bytes merely because both symbolic contexts refer to them. Per-value parsing or file ceilings remain implementation limits under Decision B, not authoritative restrictions on permitted external outcomes.
