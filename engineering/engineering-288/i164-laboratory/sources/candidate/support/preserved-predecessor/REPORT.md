A refused or unanswered authenticated request can retain a malformed body: its exact JSON evidence is represented separately and never authorizes the attempted action.

The capsule parser admits additional JSON beyond its two required keys. Recursive JSON union/directory templates therefore preserve unknown keys and nested values; they do not restrict the domain to saved examples. The same mechanism preserves refused/unanswered bodies. This does not establish a finite lifetime directory or full-domain byte capacity. The validator's local recursion ceiling remains fail-closed and is not an adopted source bound.

These are supporting declarations derived from original encodings, not new runtime fields or a change to accepted serialization. Inapplicability requires the relevant validated source guard; a caller-supplied absent flag supplies no qualification.

`static_ingest.py` runs source-template validation before the existing reviewed supporting ingestion path and carries the complete declaration bundle into its model input. IA-01's corrected response envelopes and selector joins remain intact. The existing candidate and adapter modules are unchanged.

`reconcile_baseline.py` requires a separately pinned canonical-input statement, exact baseline membership/bytes/hashes, two context identities and a complete ordered list of delta digests through an expected HEAD. It validates source identities, ordinals, predecessor links, baseline consistency, class uniqueness, immutable source/class preservation, after-state class digests and parent existence/acyclicity. It neither allocates canonical IDs nor overwrites old classes. It refuses missing or reordered deltas, mixed/stale inputs and conflicts.

The pin is a trust input. Computing a hash of one's own statement does not establish authority or completeness. This program reports exact pinned-input correspondence only and explicitly does not authenticate the canonical authority provenance.
